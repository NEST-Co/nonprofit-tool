# Concept base

Shared Astro starter for the Nest Co. portfolio concept sites. Copy this folder to start a new site, then:
1. Rename in `package.json`, set `site` in `astro.config.mjs`.
2. Override the `--brand`, `--display` and `--body` tokens in the site's own stylesheet.
3. Keep the accessibility defaults in `src/styles/global.css` and `src/layouts/Base.astro`.

Every concept site is fictional and labelled so in the footer banner. No real organizations, names or logos.
